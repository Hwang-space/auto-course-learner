# 网校自动刷课助手

ScriptCat 用户脚本，自动完成网校课程学习。

## 功能

- 一键收集未完成课程并批量打开
- 自动跳转视频播放页
- 播放过程中自动跳过答题弹窗
- 视频播放完毕自动进入下一节

## 安装

1. 安装 [ScriptCat](https://docs.scriptcat.org/) 浏览器扩展
2. 点击以下链接安装脚本：

[安装脚本](https://raw.githubusercontent.com/Hwang-space/auto-course-learner/main/auto-course-learner.user.js)
