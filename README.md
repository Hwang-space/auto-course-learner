# WSYU Career Course Auto Learner

ScriptCat 用户脚本，自动完成 WSYU 网校就业指导课程学习。

## 功能

- 一键收集未完成课程并批量打开
- 自动跳转视频播放页（点击「继续学习」）
- 播放过程中自动跳过答题弹窗
- 视频播放完毕自动进入下一节
- 课程链接持久保存

## 安装

1. 安装 [ScriptCat](https://docs.scriptcat.org/) 浏览器扩展（Edge / Chrome）
2. 点击安装脚本：[wsyu-course-auto-learner.user.js](https://raw.githubusercontent.com/Hwang-space/wsyu-course-auto-learner/master/auto-course-learner.user.js)

## 使用教程

### 第一步：进入课程任务列表

打开学校网校，进入课程任务列表页面：
`https://wsyu.wnssedu.com/student/prese/studytasklist.htm`

页面右侧会出现「刷课助手」悬浮面板。

### 第二步：一键刷课

点击悬浮面板中的 **「一键刷课」** 按钮，脚本会自动：
- 扫描当前页面所有未完成课程（进度 < 100%）
- 将课程链接填入文本框并持久保存
- 依次在新标签页中打开每门课程

### 第三步：等待视频加载

- 每个课程页面会自动跳转到视频播放页
- **视频需要当前标签页处于活跃状态才会加载**，请逐个切换到各课程标签页等待视频出现

### 第四步：手动操作

- 视频开始播放后，手动将标签页静音（右键标签页 → 静音标签页）
- 脚本会自动处理答题弹窗（点击「跳过」）
- 视频播放完毕后自动跳转到下一节

### 面板说明

| 功能 | 说明 |
|------|------|
| 课程链接文本框 | 可手动编辑，一行一个课程 intro 链接 |
| 一键刷课 | 仅在任务列表页显示，收集并打开未完成课程 |
| 全部打开 | 在其他页面显示，从文本框读取链接并打开 |
| 拖拽移动 | 拖动面板标题栏可移动位置 |
| 折叠/展开 | 点击标题栏右侧 `−` / `+` |

## 更新

脚本猫会在后台自动检查脚本更新。也可手动在脚本猫管理面板中点击更新。

## 功能介绍

- **一键刷课**：在任务列表页面自动收集所有未完成课程（进度 < 100%），批量在新标签页打开
- **自动跳转**：课程详情页自动点击「继续学习」进入视频播放页
- **跳过弹窗**：播放过程中遇到答题弹窗自动点击「跳过」
- **自动下一节**：视频播放完毕后自动跳转到下一节
- **链接持久化**：课程链接保存在本地，下次打开脚本自动恢复
- **悬浮面板**：可拖拽、可折叠的控制面板，随时查看状态
